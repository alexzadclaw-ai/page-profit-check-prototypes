# Pure Windows — Page Profit Check Audit

## Quick take
Pure Windows is a good fit for a **Solution A surgical homepage cleanup** because the current site has recognizable brand value and real local-business proof, but the first-screen clarity, trust hierarchy, service grouping, and action path can be tightened without making the business feel redesigned.

**Recommendation:** preserve the current site family and rebuild the homepage around one clear primary action: **Request a Free Estimate**.

**Visual resemblance:** High  
**Audit coverage target:** High

## Site fingerprint
- **Logo/brand assets:** Text/wordmark identity and current business-name treatment preserved in a cleaner header.
- **Dominant colors:** #101820, #2f7cc0, #e8eef6, #101820.
- **Typography feel:** Impact, Arial Black, sans-serif heading feel with Helvetica Neue, Arial, sans-serif body copy direction.
- **Header/nav pattern:** Local-service navigation with phone/contact emphasis.
- **Hero/image treatment:** pure glass style visual cue with strong service promise.
- **Section rhythm:** Hero, trust strip, service cards, proof band, process block, contact section.
- **Recognizable quirks to preserve:** Wix one-page site; bold black/white hero typography; blue accent and Book Now button; Since 1986 proof; service blocks and testimonial section.

## What is already working
- The business has a live website with real local-service intent in Naperville, IL.
- The site already contains useful proof: Serving since 1986, Fully insured professionals, Homes + storefronts + offices.
- The existing visual direction is recognizable enough for Solution A instead of a full redesign.
- There is a direct contact or booking path that can be made easier to notice.

## Biggest conversion issues

1. **Critical:** Template residue such as Wix attribution/social links and split booking links can damage trust for a decades-old local service business.
   - Prototype response: Remove visible template leftovers and present one intentional estimate path.
2. **High:** The hero says window cleaning but underplays gutter cleaning, power washing, chandelier cleaning, and screen repair.
   - Prototype response: Add service grouping directly below the hero.
3. **High:** Book Now / Square / contact paths compete before explaining how estimates work.
   - Prototype response: Use “Request a Free Estimate” and explain outside-estimate process.
4. **High:** Insurance and since-1986 proof are available but not packaged as a top trust strip.
   - Prototype response: Move since 1986, fully insured, property types, and free estimates near the top.
5. **Medium:** The testimonial is useful but isolated and could sit inside a clearer proof story.
   - Prototype response: Add a proof block around the testimonial theme.

## Best Page Profit Check improvements
1. Replace scattered first-screen messaging with a clear local-service promise: “Professional window cleaning without the Wix clutter.”
2. Make **Request a Free Estimate** the primary action in the hero, process section, and contact block.
3. Move trust proof near the top: Serving since 1986, Fully insured professionals, Homes + storefronts + offices, Free outside estimates.
4. Organize services by buyer intent instead of making visitors decode every page/link.
5. Add a simple “what happens next” flow before the form or contact action.
6. Clean template residue, duplicate text, stale content, or technical form clutter where present.

## SEO basics to tighten
- Use a homepage title that combines primary service + location + brand.
- Write a concise meta description around the main service and CTA.
- Keep one clear H1 and use H2s for service categories.
- Add descriptive alt text for brand and service images if implemented in the live CMS.
- Add LocalBusiness/Service schema after the approved copy is finalized.

## Realistic implementation angle
This is a focused homepage cleanup sprint, not a rebrand. The existing site should keep its recognizable look while tightening the top section, CTA hierarchy, service grouping, trust proof, and contact expectations.
