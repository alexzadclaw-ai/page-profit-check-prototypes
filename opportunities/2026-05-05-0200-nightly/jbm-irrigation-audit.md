# JBM Landscape & Irrigation, LLC Audit

## Quick take
JBM has the ingredients of a trustworthy local contractor site: real project photos, visible phone/email, license number LI 23085, bonded/insured language, TCEQ regulatory disclosure, family-owned and veteran-owned story, and specific irrigation services. The biggest leak is that the first screen reads more like a generic Wix contractor template than a clear sprinkler/irrigation estimate path. The Solution A prototype keeps the same Wix-style contractor feel but makes the buying path faster and more specific.

## Best Page Profit Check improvements
- Rewrite hero around buyer intent: `Sprinkler Systems, Repairs & Landscape Prep` plus location and licensed contractor language.
- Replace generic CTA with `Request a Free Estimate`, plus phone CTA.
- Move LI 23085, bonded/insured, family-owned, veteran-owned trust strip immediately under hero.
- Convert service lists into two clear cards: Sprinkler System and Landscape Services, each with specific buyer tasks.
- Add a three-step `How to Get Started` section so the estimate path is visible.
- Keep project photos but make each project support credibility rather than dominate the buying path.
- Remove template leftovers from the cleaned-up experience.

## SEO basics to tighten
- Page title: use `Licensed Irrigation Contractor in Tomball, TX | JBM Landscape & Irrigation`.
- Meta description: mention sprinkler installation, repairs, redesigns, backflow repair, SOD, grading, Tomball.
- H1: include service and location rather than only company name.
- Image alt text: replace filename-style alt text with descriptive project phrases.
- LocalBusiness schema: include phone, email, locality, service area, and license if supported in site builder fields.
- Internal anchors: make Services, Projects, Contact readable and crawlable.

## Realistic implementation angle
This does not require a full rebrand. It is a surgical Wix cleanup:
1. Update hero copy, CTA labels, and top trust placement.
2. Reorganize existing service text into two or three clean cards.
3. Add a short next-steps section.
4. Refresh metadata, H1/H2s, and image alt text.
5. Remove or replace obvious template/Wix leftovers if the account plan allows it.

Realistic ROM: 4 to 8 hours for a focused Wix cleanup if all current site access and assets are available. More time only if they want a full multi-page rebuild or new photos/copy from scratch.

## Offer fit
Good fit for the $99 Page Profit Check because the business already has trust assets and real photos. The value is not inventing a new brand; it is showing exactly how the existing site can convert better with clearer irrigation positioning, trust near the top, and a simpler estimate path.
