## Side-by-side verdict
The earlier version felt like a redesign. The current Body Wise prototype is closer, but it still differs from the original in some visible ways.

## What now matches better
- two-row navigation feel
- full-width hero with centered headline
- four promo cards under the hero
- motivational quote band
- beige/gray brochure-site tone
- contact-first layout near the bottom

## Remaining differences
- not the exact original photos
- cleaner than the live site in spacing and clutter
- some sections are simplified vs the original long page
- duplicate/menu awkwardness is reduced, so it still feels a little more polished than the live page

## Recommendation
If we want this to feel almost unmistakably like the same page, the next pass should:
1. reuse exact live images if we can extract them cleanly
2. preserve more of the original spacing rhythm
3. keep more of the original section density
4. avoid smoothing the nav/footer quite so much
