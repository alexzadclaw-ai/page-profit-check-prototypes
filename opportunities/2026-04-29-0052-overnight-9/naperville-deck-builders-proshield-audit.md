# Naperville Deck Builders / ProShield Exteriors — Page Profit Check Audit

## Quick take
Naperville Deck Builders / ProShield Exteriors is a good fit for a **Solution A surgical homepage cleanup** because the current site already has recognizable local-service proof, service breadth, and reachable contact paths — but the first-screen decision flow can be made more direct without making the business feel redesigned.

**Recommendation:** preserve the current site family and rebuild the homepage around one clear primary action: **Request Project Estimate**.

**Visual resemblance:** High  
**Audit coverage target:** High

## Site fingerprint
- **Logo/brand assets:** Business-name treatment preserved in a cleaner header.
- **Dominant colors:** #183a59, #e9862f, #f5f7f3, #11263b.
- **Typography feel:** Practical local-service sans-serif with bold contractor-style display headings.
- **Header/nav pattern:** Phone/contact-forward local service navigation with fewer competing choices.
- **Hero/image treatment:** Same service-business positioning, but with the main action visible immediately.
- **Section rhythm:** Hero, trust strip, service cards, proof band, process block, contact section.
- **Recognizable quirks to preserve:**
- navy/orange exterior contractor palette
- Naperville Deck Builders SEO identity
- ProShield Exteriors brand story
- deck/porch/fence service mix
- family-owned local positioning

## What is already working
- The business has a live website with clear service intent in Naperville and Chicago suburbs, IL.
- The homepage already communicates a real local service category: custom decks, porches, fences, masonry, roofing, and home remodeling.
- The site includes direct phone, contact, quote, estimate, appointment, or booking paths.
- The brand has proof points worth preserving: 30+ years of experience, Family-owned and operated, Decks, porches and fences, Naperville and Chicago suburbs.
- The service range is broad enough to support multiple buyer-intent paths.

## Biggest conversion issues

1. **Critical:** The homepage has multiple project types competing for attention before a single estimate path is clear.
   - Prototype response: Make Request Project Estimate the primary action and organize sections by project type.

2. **High:** Deck, porch, fence, masonry, roofing, and remodeling copy repeats across blocks and can be scanned faster.
   - Prototype response: Create four project-path cards with concise descriptions.

3. **High:** 30+ years and family-owned proof should appear close to the top CTA.
   - Prototype response: Place the strongest proof in the trust strip and proof band.

4. **High:** The contact path should ask for material, timing, and project details rather than a generic inquiry.
   - Prototype response: Add a focused project-estimate panel.

## Best Page Profit Check improvements
1. Make project estimate dominant.
2. Organize broad services by project type.
3. Move family-owned proof higher.
4. Add project-specific next-step guidance.

## SEO basics to tighten
- Use a homepage title that combines primary service + location + brand.
- Write a concise meta description around the main service and CTA.
- Keep one clear H1 and use H2s for service categories.
- Add descriptive alt text for brand and service images if implemented in the live CMS.
- Add LocalBusiness/Service schema after the approved copy is finalized.

## Realistic implementation angle
This is a focused homepage cleanup sprint, not a rebrand. The existing site should keep its recognizable look while tightening the top section, CTA hierarchy, service grouping, trust proof, and contact expectations.
