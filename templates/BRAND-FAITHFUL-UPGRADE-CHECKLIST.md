# Brand-Faithful Upgrade Checklist

Use this before any Page Profit Check prototype is marked complete or committed.

## 1. Evidence collected before coding
- [ ] Original screenshot captured or a previous valid target screenshot confirmed fresh enough.
- [ ] Logo asset URL/path recorded, or reason documented if unavailable.
- [ ] Hero/background/major imagery URL/path recorded, or fallback reason documented.
- [ ] Dominant colors recorded.
- [ ] Typography feel recorded.
- [ ] Header/nav/utility rhythm recorded.
- [ ] One-sentence recognition note written: why this still feels like the same business.
- [ ] One-sentence upgrade note written: why this is clearly better than the original.

## 2. Not generic
- [ ] Prototype does not share an obvious house-template structure with unrelated leads.
- [ ] First screen uses business-specific logo, imagery, colors, typography feel, or layout cues.
- [ ] Copy names the real service/location/offer instead of generic agency filler.
- [ ] No internal terms: prototype, mockup, audit, experiment, cleanup, same business, site family.

## 3. Not a clone
- [ ] Prototype is not merely a near-copy of the old page.
- [ ] Above-the-fold message is clearer than the original.
- [ ] Primary CTA is specific and visible.
- [ ] Phone/contact/booking path is easier to find, especially on mobile.
- [ ] Services are easier to scan.
- [ ] Trust proof is moved higher or clarified.
- [ ] Visual hierarchy and spacing are improved while preserving brand DNA.

## 4. Side-by-side review
- [ ] Original and prototype screenshots are shown side by side in a timestamped lightweight report.
- [ ] Reviewer can answer “same business?” within ~3 seconds.
- [ ] Reviewer can answer “clearly better?” within ~3 seconds.
- [ ] If either answer is no, revise before commit/push.

## 5. Required final checks
- [ ] Package QA passes for the touched batch.
- [ ] Forbidden/internal wording grep is clean.
- [ ] Prototype screenshot was recaptured after the latest visual change.
- [ ] Report uses optimized external assets, not base64 bloat, unless explicitly needed.
- [ ] Report includes inline links: Original website, Prototype, Audit report, Offer letter, Contact point, Fingerprint.
