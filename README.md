# Page Profit Check Prototypes

Nightly prototype/audit workspace for Small Site Studio / Page Profit Check.

This repo is generated by the 2am lead-prototype pipeline:
- 10 curated opportunities per run
- one audit per opportunity
- one static HTML improvement prototype per opportunity
- screenshots of original target pages and prototypes
- a published summary page for review

## Current default prototype standard

The default build pattern is now **Audit-Driven Solution A**:
- preserve the prospect's visual fingerprint
- keep the site recognizable as the same business
- visibly fix the top Critical / High audit findings
- avoid turning the page into a redesign or internal commentary artifact

Use these docs/templates when building future prospects:
- `AUDIT-DRIVEN-SOLUTION-A-STANDARD.md`
- `REPEATABLE-SOLUTION-A-PIPELINE.md`
- `templates/SOLUTION-A-BRIEF-TEMPLATE.md`
- `templates/AUDIT-TO-PROTOTYPE-COVERAGE-TEMPLATE.md`
- `templates/SOLUTION-A-ACCEPTANCE-CHECKLIST.md`
- `templates/BRAND-FAITHFUL-UPGRADE-CHECKLIST.md`

## Canonical rule

If a future prospect needs a Solution A prototype, treat `AUDIT-DRIVEN-SOLUTION-A-STANDARD.md` + `REPEATABLE-SOLUTION-A-PIPELINE.md` as the source of truth.

Do not ship internal commentary or prototype self-labeling inside the page itself.
